# 🔐 Hasenha Backend

الواجهة الخلفية الآمنة لأداة حصّنها لتوليد وفحص كلمات المرور.

## ✨ المميزات

- ✅ **فحص كلمات المرور** مع Have I Been Pwned API
- 📊 **إحصاءات مجهولة** تماماً
- 🛡️ **أمان متقدم** وحماية من الثغرات
- 🔒 **لا تخزين بيانات شخصية** مطلقاً
- ⚡ **أداء عالي** مع SQLite
- **🔐 تشفير عسكري المستوى** - AES-256-GCM مع authentication
- **🤖 ذكاء اصطناعي** لكشف الشذوذ والتهديدات
- **🚀 نظام متعدد النوى** - استغلال كامل لموارد السيرفر
- **🛡️ جدار ناري ذكي** - كشف ومنع الهجمات تلقائياً
- **⚡ كاش ذكي مشفر** - لأداء فائق مع أمان
- **📊 مراقبة حية** - إحصائيات أمنية فورية
- **🔍 فحص أمني تلقائي** - اكتشاف الثغرات
- **🎯 معدل طلبات ذكي** - حماية ديناميكية

## 🚀 خطوات التشغيل

```bash
# 1. تثبيت dependencies المتقدمة
cd backend
npm install

# 2. تشغيل فحص الأمان
npm run security-scan

# 3. تشغيل بنظام الكلستر (موصى به للإنتاج)
npm run cluster

# 4. أو تشغيل عادي
npm run dev

# 5. فحص الأداء
npm run benchmark
```
