## 🛠️ التثبيت

### المتطلبات الأساسية
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- اتصال إنترنت (لتحميل الصفحة فقط)

### الطريقة السريعة
```bash
# انسخ المشروع
git clone https://github.com/B2nd9R/hasenha.git

# ادخل للمجلد
cd hasenha

# افتح التطبيق
open index.html
```

### طرق بديلة
```bash
# باستخدام Python
python -m http.server 8000

# باستخدام Node.js
npx http-server

# باستخدام PHP
php -S localhost:8000
```

## 💡 كيفية الاستخدام

### 🔑 خطوات توليد كلمات المرور

### أنواع كلمات المرور المدعومة

- **🔐 قوية**: مزيج من أحرف، أرقام، ورموز
- **🧠 سهلة التذكر**: كلمات مترابطة وآمنة
- **#️⃣ رموز PIN**: لأجهزة الهاتف والتطبيقات
- **🎨 مخصصة**: تحكم كامل في أنواع الأحرف
